# 技能创建智能体：提示词模板与环境检测

内部 Agent 平台的技能创建智能体（Skill Creator）的系统提示词模板，以及确定沙箱环境事实用的检测脚本。

## 文件

| 文件 | 作用 |
|---|---|
| `技能创建智能体-提示词模板.md` | 系统提示词模板，第 3 节留有空位 |
| `环境检测.py` | 在沙箱里运行一次，输出“平台事实” |
| `环境检测-使用说明.md` | 操作步骤、检测提示词、人工清单、最小技能实测 |

## 使用顺序

1. 按《环境检测-使用说明》第二节、第三节运行检测脚本。
2. 把输出的“平台事实”粘贴进模板第 3 节。
3. 按使用说明第四节的人工清单问平台开发，把答案补进平台事实。
4. 把模板全文设为技能创建智能体的系统提示词。

## 维护约定

- 平台升级或更换沙箱镜像后，重跑 `环境检测.py`，替换模板第 3 节。
- 每踩到一个新的平台限制，补进模板对应位置。
- 本仓库只放规范文本，不放内部样本数据、真实业务字段和配置。
